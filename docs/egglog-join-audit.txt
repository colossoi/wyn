CAUSE
Egglog 3.0 puts primitive calls in post-join instructions. A vec-at, vec-of,
set-diff, or other computation can appear to connect two table lookups in the
source while leaving the actual table join disconnected or weakly constrained.
The engine enumerates unrelated candidates, then executes the primitive and
rejects mismatches. Reordering source clauses does not repair that connection.

DO NOT TURN EVERY PRIMITIVE INTO A TABLE
Primitive computations used only in rule heads, terminal arithmetic/filter
operations with bound inputs, and literal empty containers do not by themselves
introduce this defect. The flow.egg rules use explicit relational keys and have
no instance of the delayed container-element bridge found above.

The generic shared-first-key probe demonstrates that a partially connected
join can still be quadratic. However, current production effect sets are built
from SharedRead, SharedWrite, and OrderedEffect. Their finite domain bounds
Commutes/ReadOnlyEffects variants. Do not report that generic probe as proof of
an unbounded production effect-set problem. Revisit if richer effects are used.

Generated range-midpoint/end-index queries and intentional pairwise analyses
(e.g. same-expression CSE and transitive relations) are different from an
unrelated global product. They remain review candidates where appropriate;
the scanner's component count is evidence for inspection, not a bug verdict.
